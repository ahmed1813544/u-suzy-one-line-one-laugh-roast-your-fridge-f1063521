A single original line roasting a fridge, written by a stdlib-only Python
program (`main.py`, Python 3.13). Running it writes exactly one line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), byte-identical
on every run.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> My fridge's crisper drawer is just a vegetable morgue with mood lighting.
